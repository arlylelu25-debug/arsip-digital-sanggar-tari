## 2. Karakteristik Tiap Jenis Data

**a. Video Pertunjukan**
- Apa: Rekaman lengkap tari di atas panggung
- Mengapa: Arsip budaya, promosi, evaluasi
- Di Mana: Di panggung
- Kapan: Saat pentas
- Siapa: Pelatih dan perekam video
- Bagaimana: Format MP4/MOV, ukuran besar 2-4 GB

**b. Video Latihan**
- Apa: Rekaman latihan harian
- Mengapa: Bahan belajar ulang penari baru
- Di Mana: Di sanggar
- Kapan: Rutin mingguan
- Siapa: Pelatih dan murid
- Bagaimana: Format MP4 720p-1080p

**c. Audio Gamelan**
- Apa: File musik pengiring
- Mengapa: Sumber utama irama tari
- Di Mana: Studio rekaman
- Kapan: Dibuat sekali, dipakai terus
- Siapa: Penabuh gamelan
- Bagaimana: Format WAV dan MP3

**d. Foto Dokumentasi**
- Apa: Foto kostum, rias, pose gerakan
- Mengapa: Referensi kostum dan bahan ajar
- Di Mana: Sanggar dan belakang panggung
- Kapan: Saat buat kostum dan pentas
- Siapa: Penjahit dan fotografer
- Bagaimana: Format JPG/RAW

**e. Dokumen Koreografi**
- Apa: Catatan hitungan dan pola lantai
- Mengapa: Kekayaan intelektual utama sanggar
- Di Mana: Kantor sanggar
- Kapan: Saat cipta tari baru
- Siapa: Pelatih inti
- Bagaimana: Format PDF/DOCX, rahasia

**f. Administrasi**
- Apa: Daftar anggota, keuangan, surat
- Mengapa: Operasional harian
- Di Mana: Kantor sanggar
- Kapan: Harian
- Siapa: Pengurus
- Bagaimana: Format PDF/XLSX

**g. Aset Desain**
- Apa: Poster, banner, logo
- Mengapa: Promosi acara
- Di Mana: Komputer desainer
- Kapan: Saat ada pentas besar
- Siapa: Tim publikasi
- Bagaimana: Format PSD/AI/JPG
