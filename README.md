ANALISIS KEBUTUHAN ARSIP DIGITAL SANGGAR TARI

1. Daftar Jenis Data yang Dibutuhkan
1. Video Pertunjukan dan Pentas
2. Video Latihan dan Tutorial
3. Audio Musik Pengiring Gamelan
4. Foto Dokumentasi Kostum dan Gerakan
5. Dokumen Koreografi dan Naskah Tari
6. Dokumen Administrasi Sanggar
7. Aset Desain Grafis dan Publikasi

2. Karakteristik Tiap Jenis Data (Kerangka 6 Pertanyaan)

a. Video Pertunjukan
Apa: Rekaman lengkap tari di atas panggung
Mengapa: Untuk arsip budaya, promosi, dan evaluasi
Di Mana: Di panggung
Kapan: Saat pentas
Siapa: Pelatih dan perekam video
Bagaimana: Format MP4/MOV, ukuran besar

b. Video Latihan
Apa: Rekaman proses latihan harian
Mengapa: Bahan belajar ulang penari baru
Di Mana: Di sanggar
Kapan: Rutin mingguan
Siapa: Pelatih dan murid
Bagaimana: Format MP4 resolusi sedang

c. Audio Musik
Apa: File musik pengiring
Mengapa: Sumber utama latihan
Di Mana: Studio rekaman
Kapan: Dibuat sekali, dipakai terus
Siapa: Penabuh gamelan
Bagaimana: Format WAV dan MP3

d. Foto Dokumentasi
Apa: Foto kostum, rias, pose
Mengapa: Referensi kostum dan bahan ajar
Di Mana: Sanggar dan belakang panggung
Kapan: Saat buat kostum dan pentas
Siapa: Penjahit dan fotografer
Bagaimana: Format JPG/RAW

e. Dokumen Koreografi
Apa: Catatan hitungan dan pola lantai
Mengapa: Kekayaan utama sanggar
Di Mana: Kantor sanggar
Kapan: Saat cipta tari baru
Siapa: Pelatih inti
Bagaimana: Format PDF/DOCX, rahasia

f. Administrasi
Apa: Daftar anggota, keuangan, surat
Mengapa: Operasional sanggar
Di Mana: Kantor sanggar
Kapan: Harian
Siapa: Pengurus
Bagaimana: Format PDF/XLSX

3. Asumsi Jumlah Unit dan Ukuran Rata-rata
Video Pentas: 50 video x 3 GB = 150 GB
Video Latihan: 200 video x 800 MB = 160 GB
Audio Gamelan: 100 file x 50 MB = 5 GB
Foto Dokumentasi: 2500 foto x 8 MB = 20 GB
Dokumen Koreografi: 50 file x 5 MB = 0.25 GB
Administrasi: 300 file x 2 MB = 0.6 GB
Aset Desain: 100 file x 150 MB = 15 GB
